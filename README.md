## 🛠️ Getting Started

### Prerequisites
Before you begin, ensure you have the following installed:
- **Java 17**: Make sure your environment is set to use Java 17.
- **Android Studio**: Recommended IDE for Android development.
- **Gradle**: The project uses Gradle for building and dependency management.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/<cherriedy>/<ban-hang-so>.git
   ```
2. Open the project in **Android Studio**.
3. Sync the Gradle files to download all dependencies.
4. Build the project.
